# Integration branding

This directory contains repository branding for the R4875G1 Charger Home Assistant integration.

Files:

- `icon.png` — 256 x 256 PNG, square integration icon
- `logo.png` — 768 x 256 PNG, landscape integration logo

The assets use the same visual identity as the R4875G1 Charger Dashboard while remaining distinguishable through the Home Assistant integration symbol.

The README references `logo.png` through an absolute raw GitHub URL so that HACS can render it outside the normal repository-relative context.
